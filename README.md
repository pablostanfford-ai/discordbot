# Telegram HelpDesk — бот технической поддержки + Mini App

Мини-приложение для Telegram: клиенты обращаются в поддержку по техническим
вопросам через бота, а оператор просматривает тикеты и решает проблемы через
чат прямо в панели (ответы доставляются клиенту в личку через бота).

> ⚠️ Discord-бот + дашборд (бывшие папки `bot/` и `web/`) — **отдельный проект**,
> из этого репозитория удалён. К HelpDesk он не имеет отношения и вместе с ним
> не запускается.

## Возможности
- 🎫 Приём обращений: `/start` → категория (вход / сеть / оплата / баг / другое) → описание
- 💬 Любой текст клиента автоматически добавляется в его открытый тикет
- 📷 Скриншоты: клиент присылает фото — оно сохраняется и показывается в чате панели
- 🛠 Mini App «Панель тикетов»: список с фильтрами, поиск, счётчики нечитанного
- ✍️ Ответ оператором уходит клиенту в Telegram; статусы тикета с уведомлениями
- 🏷 Теги на тикетах + облако тегов для фильтрации
- ⏱ SLA: дедлайн первого ответа по категории, подсветка просроченных тикетов
  и автоматические уведомления операторов в личку
- 🔐 Безопасность: проверка `initData` по HMAC-подписи Telegram + JWT-сессия,
  ограничение доступа по `TELEGRAM_ADMIN_IDS`

## Структура
```
helpdesk/
├── main.py           # точка входа: бот (aiogram) + веб (uvicorn) в одном процессе
├── config.py         # настройки из .env
├── auth.py           # initData HMAC + JWT
├── store.py          # JSON-хранилище тикетов, теги, SLA
├── tg_bot.py         # бот поддержки, уведомления админам, скачивание скриншотов, SLA-монитор
└── webapp/           # FastAPI REST API + Mini App (HTML/CSS/JS)
data/telegram/        # tickets.json (runtime)
data/photos/          # скриншоты из тикетов (раздаются по /photos/<file>)
```

## Быстрый старт
1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. `cp .env.example .env` и заполните:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_ADMIN_IDS` — ваш telegram id (узнать: @userinfobot)
   - `TG_BASE_URL` — публичный **HTTPS** URL (для прода; локально можно localhost)
3. `bash run.sh` → панель на http://localhost:8060/app + запустится бот.
4. В @BotFather: `Bot Settings → Menu Button → Configure menu button` →
   URL = `https://ваш-домен/app`. Либо используйте кнопку «🛠 Открыть панель
   тикетов» (`/panel`) и кнопки «💬 Ответить в чате» в уведомлениях.

### Dev-режим (без токена)
Если `TELEGRAM_BOT_TOKEN` пуст — запускается только панель; на экране входа
есть кнопки «Подключиться (dev-режим)» и «Засеять демо-тикеты».

### HTTPS для продакшена
Telegram открывает Mini App только по HTTPS. Проще всего — cloudflared:
```
cloudflared tunnel --url http://localhost:8060
```
(или свой домен + nginx/caddy + Let's Encrypt). URL туннеля → в `TG_BASE_URL` и в Menu Button.

## API (для интеграций)
| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth` | обмен `initData` на сессию (cookie) |
| GET | `/api/tickets?status=&search=&tag=` | список + статистика + все теги |
| GET | `/api/tickets/{id}` | тикет с полной историей (отметка прочтения) |
| POST | `/api/tickets/{id}/reply` | ответ оператором → доставляется клиенту |
| POST | `/api/tickets/{id}/status` | смена статуса → уведомление клиенту |
| POST | `/api/tickets/{id}/tags` | установить теги тикета |
| GET | `/photos/<file>` | скачанные скриншоты клиентов |

## SLA
Дедлайны первого ответа (настраиваются в `helpdesk/store.py`, `SLA_SECONDS`):
вход — 2 ч, сеть/оплата — 4 ч, баг — 8 ч, другое — 12 ч. Монитор раз в минуту
проверяет непросроченные-без-ответа тикеты и шлёт операторам предупреждение.
